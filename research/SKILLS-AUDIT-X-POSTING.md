## My take (ENI)

- **No dedicated short-form/copywriting skill existed** — I created one: `x-post-craft` (voice rules + formats + the draft-queue flow + the never-chase-attention rule). That is the skill every post draft should run through.
- **The content engine stack:** `last30days` + `reddit-reading` + `blogwatcher`/`rss-feeds` + `polymarket` (trends) → `consciousness-council`/`dhdna-profiler` (angles) → `x-post-craft` (writing) → `generate-image`/`pillow-pin-factory`/`infographics`/`excalidraw`/`comfyui` (visuals) → `quote_publish.py`/`post_publish.py` (firing) → `x-growth-op` (measurement).
- **Biggest underused gems for the 500K goal:** `seo-microtool-builder` (build the utility, then post it — copy-link weight 20.0), `dhdna-profiler` (reverse-engineer why bangers work), `infographics` + `excalidraw` (saveable content), `x-article-publisher-skill` (the 'serious to know about' lane).
- **Keep short & scannable** (your rule): most posts 45–110 chars; longer only for utility/explainer pieces; articles for the deep ones.
